# Frank 项目中文注释导读

这个分支用于学习 Frank 的代码结构，已经为项目中最核心的前后端链路添加了中文注释。建议不要从所有文件逐行看起，而是按调用链阅读。

## 1. 推荐阅读顺序

### 第一组：Tauri 应用入口

1. `src-tauri/src/main.rs`
   - Rust 程序入口。
   - 只负责调用 `frank_lib::run()`。

2. `src-tauri/src/lib.rs`
   - Tauri 后端主配置。
   - 注册全局状态 `FrankState`。
   - 注册前端可调用的 Rust command。
   - 安装窗口、HTTP、Shell、单实例等插件。

### 第二组：前端调用 LCU 的统一入口

3. `src/lcu/index.ts`
   - 前端所有 LCU 请求的统一封装。
   - 调用 `invoke("invoke_lcu", ...)` 进入 Rust 后端。

4. `src-tauri/src/lcu.rs`
   - Rust command 层。
   - 初始化全局 `REST_CLIENT`。
   - 处理 `invoke_lcu`、启动监听、启动游戏、配置无边框等功能。

5. `src-tauri/src/shaco/rest.rs`
   - 真正向 LCU 本地 HTTPS 接口发 GET/POST/PATCH/DELETE 请求。

6. `src-tauri/src/shaco/utils/process_info.rs`
   - 从 `LeagueClientUx.exe` 进程启动参数里解析 LCU 的 port、token 和 region。

### 第三组：LCU WebSocket 事件流

7. `src-tauri/src/lcu/listener.rs`
   - 订阅 LCU WebSocket 事件。
   - 把 gameflow、champ-select、current-champion 等事件转发给前端 background 窗口。

8. `src/background/background.ts`
   - 隐藏后台窗口的主逻辑。
   - 监听 Rust 端发来的事件。
   - 根据游戏阶段触发自动接受、自动 BP、窗口显示隐藏等动作。

9. `src/background/gameFlow.ts`
   - 游戏流程协调器。
   - 把 `ReadyCheck`、`ChampSelect`、`GameStart` 等状态转换成具体业务行为。

### 第四组：桌面窗口与本地能力

10. `src-tauri/src/lol_window_tracker.rs`
    - 使用 Win32 API 查找 LOL 窗口。
    - 使用 DWM 获取真实窗口边界。
    - 把 Frank 主窗口吸附到 LOL 窗口左右侧。

11. `src/background/utils/creatWindow.ts`
    - 动态创建 mainWindow、queryMatchWindow、matchAnalysisWindow、recentMatchWindow。
    - 理解 Frank 的多窗口/多入口结构。

12. `src/background/utils/tray.ts`
    - 创建系统托盘图标和右键菜单。
    - 控制主窗口、对局详情窗口、我的战绩窗口显示/隐藏。

13. `src/background/utils/config.ts`
    - 初始化 localStorage 配置。
    - 补齐旧版本缺失配置项。
    - 从 LCU 读取 LOL 客户端路径。

### 第五组：主窗口状态机

14. `src/main/main.ts`
    - mainWindow 的 Vue 应用入口。
    - 注册 Router 和 Pinia。

15. `src/main/main.vue`
    - Naive UI 全局主题、语言、消息和弹窗 Provider。

16. `src/main/index.vue`
    - mainWindow 的核心状态机。
    - 监听 background 发来的 `clientStatus`。
    - 根据游戏阶段切换 home/rank/teammate/rune/record 页面。
    - 在多个窗口之间转发缓存数据。

17. `src/main/router/index.ts`
    - 自动扫描 `views/**/index.vue` 生成路由。

### 第六组：首页、符文、队友、排位笔记页面

18. `src/main/views/home/index.vue`
    - 首页展示召唤师基础信息、段位、熟练度和客户端启动状态。

19. `src/main/views/home/getHomeData.ts`
    - 聚合首页需要的召唤师、段位、荣誉、熟练度数据。

20. `src/main/views/home/startGame.vue`

    - 调用 Rust command 启动 LOL 客户端。

21. `src/main/views/home/checkMode.vue` / `FloatingPrompt.vue`

22. `src/main/views/rune/index.vue`
    - 符文页入口，组合 RuneHeader 和 RuneMain。

23. `src/main/views/rune/runeHeader.vue`
    - 英雄头像、技能加点、自动符文入口。
    - 监听当前英雄变化并自动应用已保存的自动符文。

24. `src/main/views/rune/runeMain.vue`
    - 推荐符文、官方符文、装备方案、海克斯数据 Tabs。

25. `src/main/views/rune/runeContent.vue`
    - 符文卡片展示和“应用符文”按钮。

26. `src/main/views/rune/runes.ts`
    - 当前符文读取、符文页写入、自动符文 localStorage 缓存。

27. `src/main/views/rune/queryRune.ts`
    - 请求远程推荐符文/出装/技能数据。
    - 将远程 JSON 转换成页面和客户端可用的结构。

28. `src/main/views/teammate/index.vue`
    - 队友页入口和对局分析窗口入口。

29. `src/main/views/teammate/summonerList.vue`
    - 队友列表、近期战绩、黑名单抽屉。

31. `src/main/views/teammate/queryMatch.ts`
    - 队友近期战绩查询与 SimpleMatchTypes 转换。

32. `src/main/views/record/index.vue`

    - 展示黑名单列表和对局结束添加记录抽屉。

### 第七组：Store、对局详情和游戏内窗口

33. `src/main/store/useRune.ts`
    - 符文页面的 Pinia Store。
    - 可以类比为 WPF/MVVM 中的 ViewModel。

34. `src/main/store/useTeammate.ts`
    - 队友页面 Store。
    - 查询近期战绩、缓存队友战绩、合并黑名单数据。

35. `src/main/store/useRecord.ts`
    - 战绩/黑名单 Store。
    - 处理对局结束数据、黑名单检查和 PlanB 兜底数据。

36. `src/queryMatch/utils/matchDetails.ts`
    - 查询单局对局详情。
    - 计算双方数据、MVP、全场最高图标、伤害/经济百分比等。

37. `src/queryMatch/utils/MatchDetail.d.ts`
    - 对局详情相关 TypeScript 类型定义。

38. `src/recentMatch/main.ts` / `main.vue`

39. `src/recentMatch/recentMatch.vue`
    - 游戏内近期战绩主窗口。

40. `src/recentMatch/utils/querySummoner.ts`
    - 从 LCU 当前 session 获取双方队伍、段位、熟练度/绝活标签。

41. `src/recentMatch/utils/queryMatch.ts`

## 2. 最重要的调用链

### 前端主动调用 LCU REST

```text
Vue 页面 / TS 业务模块
  -> invokeLcu(method, uri, body)
  -> Tauri invoke("invoke_lcu")
  -> Rust lcu.rs::invoke_lcu
  -> RESTClient.get/post/patch/delete
  -> https://127.0.0.1:{LCU_PORT}{uri}
```

### LCU 状态事件推送到前端

```text
League Client LCU WebSocket
  -> Rust listener.rs
  -> app.emit_to("background", "client_status", status)
  -> background.ts::handleClientStatus
  -> gameFlow.ts 对应业务动作
  -> emitTo("mainWindow", "clientStatus", ...)
  -> main/index.vue::GameState
  -> 主窗口 UI 刷新 / 页面切换
```

### 主窗口页面切换

```text
background 发出 clientStatus
  -> main/index.vue 监听 clientStatus
  -> GameState.handleXXX()
  -> changeState(id, page, index)
  -> router.push({ name: page })
  -> router-view 显示对应页面
```

### 首页初始化

```text
home/index.vue
  -> getCurrentSummonerAllInfo()
  -> querySummonerInfo / queryRankPoint / querySummonerHonorLevel / queryMasteryChampList
  -> writeSumInfo()
  -> localStorage.sumInfo
  -> recordStore.init()
```

### 自动接受对局

```text
LCU 推送 ReadyCheck
  -> background.ts::handleClientStatus("ReadyCheck")
  -> gameFlow.autoAcceptGame()
  -> invokeLcu("post", "/lol-matchmaking/v1/ready-check/accept")
```

### 自动 BP

```text
LCU 推送 ChampSelect
  -> background.ts::handleClientStatus("ChampSelect")
  -> gameFlow.autoPickBanChamp()
  -> autoBP.ts::champSelectSession()
  -> GET /lol-champ-select/v1/session
  -> 找到本地玩家正在进行的 action
  -> PATCH /lol-champ-select/v1/session/actions/{actionID}
```

### 应用符文

```text
符文页面点击应用
  -> runeContent.vue::applyRune()
  -> runes.ts::handleRunesWrite()
  -> aboutRune.ts::applyRunePage(data)
  -> GET /lol-perks/v1/pages
  -> DELETE /lol-perks/v1/pages/{id}
  -> POST /lol-perks/v1/pages
```

### 队友页初始化

```text
main/index.vue 收到 ChampSelect
  -> queryFriendInfo()
  -> /lol-champ-select/v1/session
  -> 获取 myTeam summonerId
  -> 查询召唤师信息和段位
  -> useTeammateStore.initStore()
  -> 查询近期战绩并缓存
```

### 游戏内 recentMatchWindow

```text
GameStart
  -> background/gameFlow.ts 创建 RecentMatchWindow
  -> recentMatch.vue mounted
  -> emitTo("mainWindow", "cacheMatchList", "getMatchList")
  -> main/index.vue 回传 matchListCache
  -> recentMatch.vue 合并缓存和实时查询
  -> 展示双方近期战绩
```

### 对局详情

```text
点击某局详情
  -> matchDetails.queryGameDetail(gameId, summonerId)
  -> GET /lol-match-history/v1/games/{gameId}
  -> 解析 participants / participantIdentities
  -> 生成 ParticipantsInfo
  -> matchContent.vue 展示详情
```

### 窗口吸附

```text
mainWindow 创建完成
  -> creatWindow.ts 同步 lolTracker 配置
  -> Rust sync_tracker_config
  -> Rust start_tracking_loop
  -> lol_window_tracker.rs 查找 League of Legends 窗口
  -> DwmGetWindowAttribute 获取真实边界
  -> window.set_position 移动 Frank 主窗口
```

## 3. 结合 C# / WPF / WinForms 的类比

| Frank 技术 | C# 桌面开发类比 |
|---|---|
| Tauri window | WPF Window / WinForms Form |
| background 隐藏窗口 | 后台常驻窗口 / 托盘程序主调度器 |
| Vue component | UserControl / Page |
| Pinia Store | ViewModel / 状态容器 |
| Tauri command | C# 后台服务方法 / IPC 接口 |
| Rust `AppHandle.emit_to` | 事件总线 / Messenger |
| LCU REST | 本地 HttpClient 调用 |
| LCU WebSocket | 客户端事件订阅 |
| `Arc<Mutex<T>>` | 跨线程共享对象 + lock |
| `AtomicBool` | 线程安全 bool 标志位 |
| `WebviewWindow` | 动态创建窗口实例 |
| Tauri Tray | WinForms NotifyIcon / 托盘菜单 |
| Pinia Store | ViewModel / 单例状态服务 |
| `emitTo` / `listen` | Messenger / EventAggregator |
