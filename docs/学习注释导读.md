# Frank 项目中文注释导读

这个分支用于学习 Frank 的代码结构，已经为项目中最核心的前后端链路添加了中文注释。建议不要从所有文件逐行看起，而是按调用链阅读。

## 1. 推荐阅读顺序

### 第一组：Tauri 应用入口

1. `src-tauri/src/main.rs`
   - Rust 程序入口。
   - 只负责调用 `frank_lib::run()`。

2. `src-tauri/src/lib.rs`
   - Tauri 后端主配置。
   - 注册全局状态 `FrankState`。
   - 注册前端可调用的 Rust command。
   - 安装窗口、HTTP、Shell、单实例等插件。

### 第二组：前端调用 LCU 的统一入口

3. `src/lcu/index.ts`
   - 前端所有 LCU 请求的统一封装。
   - 调用 `invoke("invoke_lcu", ...)` 进入 Rust 后端。

4. `src-tauri/src/lcu.rs`
   - Rust command 层。
   - 初始化全局 `REST_CLIENT`。
   - 处理 `invoke_lcu`、启动监听、启动游戏、配置无边框等功能。

5. `src-tauri/src/shaco/rest.rs`
   - 真正向 LCU 本地 HTTPS 接口发 GET/POST/PATCH/DELETE 请求。

6. `src-tauri/src/shaco/utils/process_info.rs`
   - 从 `LeagueClientUx.exe` 进程启动参数里解析 LCU 的 port、token 和 region。

### 第三组：LCU WebSocket 事件流

7. `src-tauri/src/lcu/listener.rs`
   - 订阅 LCU WebSocket 事件。
   - 把 gameflow、champ-select、current-champion 等事件转发给前端 background 窗口。

8. `src/background/background.ts`
   - 隐藏后台窗口的主逻辑。
   - 监听 Rust 端发来的事件。
   - 根据游戏阶段触发自动接受、自动 BP、窗口显示隐藏等动作。

9. `src/background/gameFlow.ts`
   - 游戏流程协调器。
   - 把 `ReadyCheck`、`ChampSelect`、`GameStart` 等状态转换成具体业务行为。

### 第四组：核心功能模块

10. `src/lcu/autoBP.ts`
    - 自动选择/禁用英雄。
    - 通过 PATCH `/lol-champ-select/v1/session/actions/{actionID}` 完成 pick/ban。

11. `src/lcu/aboutRune.ts`
    - 应用推荐符文页。
    - 读取符文页、删除可删除符文页、创建新符文页。

12. `src/main/store/useRune.ts`
    - 符文页面的 Pinia Store。
    - 可以类比为 WPF/MVVM 中的 ViewModel。

13. `src/main/router/index.ts`
    - 自动扫描 `views/**/index.vue` 生成路由。

## 2. 最重要的调用链

### 前端主动调用 LCU REST

```text
Vue 页面 / TS 业务模块
  -> invokeLcu(method, uri, body)
  -> Tauri invoke("invoke_lcu")
  -> Rust lcu.rs::invoke_lcu
  -> RESTClient.get/post/patch/delete
  -> https://127.0.0.1:{LCU_PORT}{uri}
```

### LCU 状态事件推送到前端

```text
League Client LCU WebSocket
  -> Rust listener.rs
  -> app.emit_to("background", "client_status", status)
  -> background.ts::handleClientStatus
  -> gameFlow.ts 对应业务动作
  -> emitTo("mainWindow", "clientStatus", ...)
  -> 主窗口 UI 刷新
```

### 自动接受对局

```text
LCU 推送 ReadyCheck
  -> background.ts::handleClientStatus("ReadyCheck")
  -> gameFlow.autoAcceptGame()
  -> invokeLcu("post", "/lol-matchmaking/v1/ready-check/accept")
```

### 自动 BP

```text
LCU 推送 ChampSelect
  -> background.ts::handleClientStatus("ChampSelect")
  -> gameFlow.autoPickBanChamp()
  -> autoBP.ts::champSelectSession()
  -> GET /lol-champ-select/v1/session
  -> 找到本地玩家正在进行的 action
  -> PATCH /lol-champ-select/v1/session/actions/{actionID}
```

### 应用符文

```text
符文页面点击应用
  -> aboutRune.ts::applyRunePage(data)
  -> GET /lol-perks/v1/pages
  -> DELETE /lol-perks/v1/pages/{id}
  -> POST /lol-perks/v1/pages
```

## 3. 结合 C# / WPF / WinForms 的类比

| Frank 技术 | C# 桌面开发类比 |
|---|---|
| Tauri window | WPF Window / WinForms Form |
| background 隐藏窗口 | 后台常驻窗口 / 托盘程序主调度器 |
| Vue component | UserControl / Page |
| Pinia Store | ViewModel / 状态容器 |
| Tauri command | C# 后台服务方法 / IPC 接口 |
| Rust `AppHandle.emit_to` | 事件总线 / Messenger |
| LCU REST | 本地 HttpClient 调用 |
| LCU WebSocket | 客户端事件订阅 |
| `Arc<Mutex<T>>` | 跨线程共享对象 + lock |
| `AtomicBool` | 线程安全 bool 标志位 |
